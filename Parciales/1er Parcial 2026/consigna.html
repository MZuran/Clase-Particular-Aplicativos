1. JavaScript puro

Ejercicio 1.1 — Funciones de costo

Crear las siguientes funciones:

costoPorPeso(kg)

Debe devolver:

kg * 1500
costoPorDistancia(km)

Debe devolver:

km * 85.5
costoInternacional(pesos, cotizacion)

Debe devolver:

pesos / cotizacion

Ejercicio 1.2 — Función redondear

Crear la función:

redondear(numero, decimales)

La función debe:

  1. Calcular el factor: 
    const factor = Math.pow(10, decimales);
  2. Devolver: 
    Math.round(numero * factor) / factor
Pruebas

Probar en la consola:

redondear(costoPorPeso(2.5), 2)

Debe dar 3750.

redondear(costoInternacional(10000, 1350), 3)

Debe dar 7.407.

3. DOM

Ejercicio 3.1 — Formulario de cotización

Crear la función:

cotizarEnvio()
  1. Obtener el tipo de envío desde: 
    <select id="select-tipo">
    Opciones: "peso", "distancia", "internacional".
  2. Obtener el valor desde: 
    <input id="input-valor">
    Convertirlo a Number.
  3. Validar que el valor no sea NaN ni vacío. Si no se cumple alguna condición, mostrar un alert.
  4. Calcular el costo según el tipo:
    • "peso" → costoPorPeso(valor)
    • "distancia" → costoPorDistancia(valor)
    • "internacional" → costoInternacional(valor, 1350)
  5. Redondear el resultado utilizando redondear(resultado, 2).
  6. Crear un nuevo Envio utilizando nextId e incrementar nextId.
  7. Llamar a historial.agregar(envio).
  8. Mostrar el resultado en el elemento con id="resultado".
  9. Llamar a mostrarEnvios() para actualizar la lista.

Ejercicio 3.2 — Mostrar historial

Crear la función:

mostrarEnvios()
  1. Seleccionar el elemento con id="lista-historial".
  2. Recorrer historial.envios utilizando un for.
  3. Por cada envío, mostrar:
    • tipo
    • valor original
    • costo
    • fecha
    utilizando el formato: 
    ${tipo} — ${valorOriginal} → $${costo} (${fecha})
    e insertarlo dentro de una etiqueta <p>.
  4. Asignar el HTML generado al innerHTML del elemento.

Al cargar la página, llamar a:

mostrarEnvios()

utilizando window.onload.

Ejercicio 3.3 — Limpiar historial

Crear la función:

limpiarEnvios()
  1. Vaciar el array historial.envios asignándole [].
  2. Llamar a mostrarEnvios() para actualizar el DOM.
